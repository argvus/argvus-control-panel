コントロールパネルは、アクティブセッションのためのクイックアクセスQuickshellインターフェースです。フル設定アプリケーションを開かずに、状態を確認したり頻繁に行う操作を実行したりする場所です。

このパネルは、共有`argvus-i18n`カタログを使用します。**コントロールセンター → ロケールと地域**で別の言語を適用すると、選択したカタログを読み込むためにコントロールパネルサービスが自動的に再起動されます。

コントロールパネルは、タスクバーの端をARGVUSフォーカスおよびARGVUSクロックと共有しています。パネルを開くと、まず両方のポップアップが閉じられます。フォーカスやクロックを開くと、パネルが閉じられます。

## コントロールパネルまたはコントロールセンター？

現在のステータスやクイックアクションにはパネルを使用してください。永続的なデスクトップ設定を変更したい場合は、[コントロールセンター](/docs/components/argvus-control-center/)を使用してください。例えば、パネルは外観、ディスプレイ、ネットワーク、音量、明るさ、通知、電源、セッションのコントロールを表示できます。詳細なビジュアルやレイアウトの設定は**コントロールセンター → 外観**にあります。

## カード

現在のカードレジストリには以下が含まれます：

- ユーザー
- 通知
- カレンダー
- 天気
- 音量
- 明るさ
- ネットワーク
- Bluetooth
- システム
- 外観
- セッション
- ディスプレイ
- 電源

一部のカードは条件付きです。Bluetooth機能が利用できない場合はBluetoothは非表示になります。サポートされているバックライトやモニター制御ツールが利用できない場合は明るさは非表示になります。したがって、カードリストはすべてのマシンが提供できるコントロールを約束するのではなく、現在のマシンを反映しています。

## 表示と順序

パネルの **外観 → コントロールパネル** ページでは、カードを有効化、無効化、および並べ替えることができます。パッケージ化されたヘルパーも同じ状態を公開します：

```sh
cards-config.sh status
cards-config.sh set <card> enabled
cards-config.sh set <card> disabled
cards-config.sh move <card> <index>
```
可能な場合はUIを使用してください。パネルの状態はユーザー設定として保存されます。これは生成されたHyprlandのレイアウトファイルとは別です。

カードを無効にすると、パネルからは非表示になりますが、それに関連するプロバイダーはアンインストールされません。並べ替えはカードの表示順序を変更します。現在のヘルパーには`reset`サブコマンドはありません。ユーザーのカード設定が削除されると、プロバイダーは状態を既知のカードに正規化します。カードはデフォルトで有効化され、パッケージ順で表示されます。

コントロールパネルの外観カードは、もはやグローバルな透明度設定を管理しません。透明度とぼかしは、**コントロールセンター → 外観 → コントロールパネル** で個別に設定してください。コントロールパネルのマスター **有効** スイッチは、パネル全体とそのサービスを引き続き制御します。`cards-config.sh master set` はスイッチが変更されたときにのみパネルを再起動または停止します。既に設定されている値を設定しても、有効なパネルが実行されていることを確認するだけです。

## キーボード操作

パネルが開いたら、**↑/↓** キーで内容をスクロールします。**Tab** キーはボタン、コントロール、フィールド間を前に移動し、**Shift+Tab** キーは後ろに移動します。ボタンはフォーカス時にハイライトされた枠で表示され、**Enter** または **Space** キーでアクティブにできます。スライダーやテキストフィールドは、これらのキーを独自の調整や編集に使用します。**Esc** キーでパネルを閉じます。

## デスクトップの他の部分と同期を保つ

通知カードは、「おやすみモード」が有効な間、履歴を非表示にします。その期間に受信した通知は Dunst に保持され、「おやすみモード」がオフになると再びカードに表示されます。

カードはデスクトップのライブ状態を表示します。他の場所（コントロールセンター、タスクバー、キーボードショートカット、または `argvus` コマンドライン）で行った変更は、パネルを再起動せずに反映されます。

| カード | ステートの由来 | 更新タイミング |
| --- | --- | --- |
| ユーザー | `getent passwd` | パネルが開いている間は3秒ごと |
| 音量 | PipeWireのデフォルトシンク（`wpctl`）および`pactl subscribe`イベント | 各オーディオイベントで即時；安全装置として2秒ごと |
| 外観（テレメトリ、アニメーション、エフェクト） | argvus configの`/effects`セクション | パネルが開いている間は2秒ごと |
| 電源 |  `argvus config` `powerprofilesctl` | パネルが開いている間は3秒ごと |
| 天気 | ロケーションファイルおよびwttr.in/Open-Meteoプロバイダー | パネルが開いた時と15分ごと；タブは現在の天気と今後7日間の天気予報を切り替え

外観カードには2つの独立したスイッチがあります。**Animations** は `argvus effects-toggle animations toggle` を実行し、動くすべてのものを制御します。**Effects** は `argvus effects-toggle effects toggle` を実行し、ターミナル、ランチャー、ウィジェットテレメトリ、コントロールパネル、タスクバーのぼかしと透明度を一緒に切り替えます；少なくとも1つがオンのとき、オンとして表示されます。**SUPER + F6** (`argvus effects-toggle toggle`) は両方を一緒に切り替えます。どちらかを変更すると、Hyprland とテーマコンシューマーがその場で再読み込みされます：Waybar はスタイルシートを再読み込みし、パネルは IPC を介して再読み込みされ、Dunst は通知オフが有効でない場合に設定を再読み込みします。有効の場合、再読み込みは DND がオフになるまで延期されます。再起動は行われず、読み込み画面も表示されません。

タスクバーの音量アイコンやメディアキーをスクロールすると、`argvus config audio` が使用され、変更が PipeWire に適用されると同時に、音量が `/audio` に記録されます。そのため、設定のリロードによって古い音量が復元されることはありません。

## セッションの挙動

`argvus-control-panel.service` は `argvus-session` によって起動されます。パネルの開閉はセッションパネルの状態を変更しますが、すべてのカード操作が永続的な設定を意味するわけではありません。ネットワーク、オーディオ、電源、ディスプレイの操作は、それぞれの提供者または現在のデスクトップセッションに渡される場合があります。

パネル、タスクバーの余白、ウィンドウのレイアウト間の関係については [taskbar and panels](/docs/argvus-taskbar/taskbar/) を参照してください。

## ナイトライト

ディスプレイカードにはナイトライトのオン/オフスイッチとアクティブな温度が表示されます。その角やアニメーションは、他のパネルスイッチと同じテーマトークン（StickyおよびSpacedレイアウトを含む）に従います。スイッチには境界線がなく、他のパネルスイッチと同様に指差しカーソルを使用します。`argvus config display night-light status|toggle`を使用し、開いている間は2秒ごとにポーリングし、操作後は再取得します。バックエンドが利用できない場合は行が非表示になり、操作に失敗するとエラーが表示されます。スケジュールと温度は **コントロールセンター > デスクトップと入力 > ディスプレイ > ナイトライト** で設定します。手動でスケジュールされた切り替えは次の切り替えまで有効で、それ以外の場合はアクティブ化が持続します。

タスクバーのカレンダー、ARGVUSフォーカス、ARGVUS時計、およびコントロールパネルは相互に排他的です：1つを開くと他は閉じられます。

## コンパクトな多言語ラベル

天気タブは共有カタログ（現在の状況と7日間）を使用します。天気の測定値は等幅の列に配置され、ラベルは折り返され、値は揃ったままです。カレンダーの曜日略称はロケールに依存し、日曜日始まりであり、予報日のラベルも含まれます。これらは英語の略称の直訳ではありません。

ボタンはそのアイコン/ラベルのグループを利用可能な幅に合わせて配置します。ラベルに省略記号が必要な場合、ボタンにマウスを重ねるかフォーカスすると、全文が表示されます。電源プロファイルボタンもツールチップで説明文を表示します。長いスイッチの説明は折り返され、数値フィールドやユーザー入力は選択されたフォントに十分なスペースを確保します。カードの高さは折り返されたテキストに応じて伸びます。下位のカードを見るには、縦スクロールを使用してください。これらの変更により、選択されたフォントと既存のカード操作は保持されます。
