控制面板是当前会话的快速访问 Quickshell 界面。它是检查状态或执行常用操作的地方，而无需打开完整的设置应用程序。

该面板使用共享的 `argvus-i18n` 目录。当在 **控制中心 → 语言与地区** 中应用不同语言时，控制面板服务会自动重新启动，以便加载所选目录。

控制面板与 ARGVUS 焦点和 ARGVUS 时钟共享任务栏边缘。打开面板会先关闭两个弹出窗口；打开焦点或时钟会关闭面板。

## 控制面板还是控制中心？

使用面板查看当前状态和快速操作。当您想更改持久的桌面配置时，请使用 [控制中心](/docs/components/argvus-control-center/)]。例如，面板可以显示外观、显示、网络、音量、亮度、通知、电源和会话控制；详细的视觉和布局配置在 **控制中心 → 外观** 中进行。

## 卡片

当前的卡片注册表包括：

- 用户；
- 通知；
- 日历；
- 天气；
- 音量；
- 亮度；
- 网络；
- 蓝牙；
- 系统；
- 外观；
- 会话；
- 显示；
- 电源。

有些卡片是有条件的。当蓝牙功能不可用时，蓝牙卡片会隐藏。当既没有支持的背光也没有显示器控制工具时，亮度卡片会隐藏。因此，卡片列表反映了当前机器的情况，而不是承诺每台机器都能提供这些控制。

## 可见性和顺序

面板的 **外观 → 控制面板** 页面允许你启用、禁用和重新排序卡片。打包的辅助程序也显示相同的状态：

```sh
cards-config.sh status
cards-config.sh set <card> enabled
cards-config.sh set <card> disabled
cards-config.sh move <card> <index>
```
尽可能使用用户界面。面板状态会作为用户配置存储；它与生成的 Hyprland 布局文件是分开的。

禁用一个卡片会将其从面板中隐藏；它不会卸载背后的提供程序。重新排序会改变卡片呈现的顺序。当前助手中没有 `reset` 子命令。如果用户卡片偏好被移除，提供程序会将状态重新归一化为已知卡片，默认启用并按打包顺序排列。

控制面板外观卡不再管理全局透明度设置。请在 **控制中心 → 外观 → 控制面板** 中独立配置控制面板的透明度和模糊效果。控制面板主 **启用** 开关仍然控制整个界面及其服务。`cards-config.sh master set` 仅在开关状态变化时重启或停止面板；设置已存在的值只会确保启用的面板运行。

## 键盘导航

当面板打开时，使用 **↑/↓** 滚动其内容。**Tab** 在按钮、控件和字段之间向前移动；**Shift+Tab** 向后移动。按钮通过高亮边框显示焦点，并可以使用 **Enter** 或 **Space** 激活。滑块和文本字段保留这些键用于自身的调整或编辑。**Esc** 关闭面板。

## 与桌面保持同步

当“请勿打扰”处于激活状态时，通知卡会隐藏其历史记录。在此期间收到的通知会保留在 Dunst 中，并在关闭“请勿打扰”后再次出现在卡片上。

这些卡显示桌面的实时状态。在其他地方（控制中心、任务栏、键盘快捷键或 `argvus` 命令行）进行的更改会在面板中立即显示，无需重新启动：

| 卡片 | 状态来源 | 刷新时间 |
| --- | --- | --- |
| 用户 | `getent passwd` | 面板打开时每 3 秒更新一次 |
| 音量 | PipeWire 默认输出设备（`wpctl`）及 `pactl subscribe` 事件 | 每次音频事件立即更新；每 2 秒作为安全网更新一次 |
| 外观（遥测、动画和特效） | `/effects` 部分的 `argvus config` | 面板打开时每 2 秒更新一次 |
| 电源 | `powerprofilesctl` | 面板打开时每 3 秒更新一次 |
| 天气 | 位置文件及 wttr.in/Open-Meteo 提供的天气数据 | 面板打开时以及每 15 分钟更新一次；标签在当前状况与未来七天天气预报之间切换 |

外观卡有两个独立的开关。**动画** 运行 `argvus effects-toggle animations toggle` 并控制所有移动的元素。**效果** 运行 `argvus effects-toggle effects toggle`，同时切换终端、启动器、小部件遥测、控制面板和任务栏的模糊和透明度；当至少其中一个开启时，它显示为开启状态。**SUPER + F6** (`argvus effects-toggle toggle`) 同时切换两者。更改任意一个会在原地重新加载 Hyprland 和主题使用者：Waybar 会重新读取其样式表，面板通过 IPC 重新加载，Dunst 会重新加载其配置，除非“请勿打扰”处于激活状态，在这种情况下，重新加载会推迟到关闭 DND 后。没有任何程序被重启，也不会出现加载屏幕。

在任务栏音量图标上滚动以及使用多媒体按键会使用 `argvus config audio`，这会将更改应用到 PipeWire 并且还会在 `/audio` 中记录音量。因此，重新加载配置不会恢复旧音量。

## 会话行为

`argvus-control-panel.service` 由 `argvus-session` 启动。打开和关闭面板会改变会话面板状态，但这并不意味着每个卡动作都是持久配置。网络、音频、电源和显示操作可能会交给它们的提供者或当前桌面会话。

请参阅 [taskbar and panels](/docs/argvus-taskbar/taskbar/)] 了解面板、任务栏边距和窗口布局之间的关系。

## 夜间灯光

显示卡显示夜间模式开/关开关和当前温度。它的角和动画遵循与其他面板开关相同的主题标记，包括粘性布局和间隔布局。开关没有边框，并使用指针手型光标，就像其他面板开关一样。它使用 `argvus config display night-light status|toggle`，在打开时每两秒轮询一次，并在执行操作后重新获取。后端不可用时，该行会隐藏；操作失败会显示错误。调度和温度可以在 **控制中心 > 桌面与输入 > 显示器 > 夜间模式** 中进行配置。手动调度切换将在下一次过渡前持续；否则激活将是持续性的。

任务栏日历、ARGVUS 焦点、ARGVUS 时钟和控制面板是互斥的：打开其中一个会关闭其他的。

## 紧凑型多语言标签

天气标签使用共享目录（当前状况和七天）。天气测量占用等宽列；标签换行且数值保持对齐。日历的星期缩写根据本地设置且以星期天为首，包括预测日期标签。它们不是英文缩写的字面翻译。

按钮将其图标/标签组绑定到可用宽度。如果标签需要省略号，悬停或聚焦按钮会显示完整文本。电源方案按钮也会在工具提示中显示其描述性文本。长的开关描述会换行，数字字段和用户输入为所选字体保留足够空间。卡片高度会随换行文本增加；使用垂直滚动查看下方卡片。这些更改保留所选字体和现有卡片操作。
