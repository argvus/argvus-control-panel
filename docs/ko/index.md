---
title: 제어판
description: Quickshell 제어판 카드를 사용하세요.
---
제어판은 활성 세션을 위한 빠른 접근 Quickshell 인터페이스입니다. 전체 설정 애플리케이션을 열지 않고 상태를 확인하거나 자주 수행하는 작업을 수행할 수 있는 장소입니다.

패널은 공유를 사용합니다. `argvus-i18n` 카탈로그. 다른 인터페이스 언어가 **Control Center → Preferences → Language & Region → Language**에서 선택되면 제어판 서비스는 자동으로 다시 시작되므로 선택한 카탈로그를로드합니다. 이 설정은 독립적입니다 `LANG`, 형식 및 제 3 자 응용 프로그램에 대한 지역 Locale 남아. 아랍어와 Urdu는 오른쪽 왼쪽 배치를 사용합니다.

제어판은 작업 표시줄 가장자리를 ARGVUS 포커스 및 ARGVUS 시계와 공유합니다. 패널을 열면 먼저 두 팝업이 모두 닫히며, 포커스나 시계를 열면 패널이 닫힙니다.

## 제어판 또는 제어 센터?

현재 상태와 빠른 작업을 위해 패널을 사용하세요. 지속적인 데스크톱 구성을 변경하고 싶을 때는 [Control Center](/docs/components/argvus-control-center/)를 사용하세요. 예를 들어, 패널은 외관, 디스플레이, 네트워크, 볼륨, 밝기, 알림, 전원 및 세션 제어를 표시할 수 있습니다; 세부적인 시각 및 레이아웃 구성은 **Control Center → Appearance**에 속합니다.

## 카드

현재 카드 레지스트리에는 다음이 포함됩니다:

- 사용자;
- 알림;
- 캘린더;
- 날씨;
- 볼륨;
- 밝기;
- 네트워크;
- 블루투스;
- 시스템;
- 외관;
- 세션;
- 디스플레이;
- 전원.

일부 카드는 조건부입니다. 블루투스 기능이 없으면 블루투스는 숨겨집니다. 지원되는 백라이트나 모니터 제어 도구가 없으면 밝기는 숨겨집니다. 따라서 카드 목록은 현재 컴퓨터를 반영하며 모든 컴퓨터에서 제공할 수 있는 제어를 보장하지는 않습니다.

## 표시 및 순서

패널의 **외관 → 제어판** 페이지에서는 카드를 활성화, 비활성화하고 순서를 변경할 수 있습니다. 패키지화된 도우미도 동일한 상태를 제공합니다:

```sh
cards-config.sh status
cards-config.sh set <card> enabled
cards-config.sh set <card> disabled
cards-config.sh move <card> <index>
```
가능하면 UI를 사용하세요. 패널 상태는 사용자 설정으로 저장되며, 생성된 Hyprland 레이아웃 파일과는 별개입니다.

카드를 비활성화하면 패널에서 숨겨지지만, 해당 카드 뒤의 제공자는 제거되지 않습니다. 카드 순서를 변경하면 카드가 표시되는 순서가 바뀝니다. 현재 헬퍼에는 `reset` 하위 명령어가 없습니다. 사용자 카드 환경설정을 제거하면, 제공자는 상태를 기본적으로 활성화되고 패키지 순서대로 존재하는 알려진 카드로 정상화합니다.

제어판 Appearance 카드에서 더 이상 글로벌 투명도 설정을 관리하지 않습니다. **제어센터 → Appearance → Control Panel**에서 제어판의 투명도 및 블러를 개별적으로 구성하세요. 제어판의 마스터 **활성화** 스위치는 여전히 전체 패널과 서비스를 제어합니다. `cards-config.sh master set`는 스위치가 변경될 때만 패널을 재시작하거나 중지하며, 이미 설정된 값을 설정하면 활성화된 패널이 실행되도록 보장합니다.

## 키보드 탐색

패널이 열리면 콘텐츠를 스크롤하기 위해 **↑/↓**를 사용하세요. **Tab**은 버튼, 컨트롤 및 필드를 순방향으로 이동하며, **Shift+Tab**은 역방향으로 이동합니다. 버튼은 강조된 테두리로 포커스를 나타내며, **Enter** 또는 **Space**로 활성화할 수 있습니다. 슬라이더와 텍스트 필드는 자체 조정이나 편집을 위해 해당 키를 사용합니다. **Esc**는 패널을 닫습니다.

## 데스크탑과 동기화 유지

알림 카드(Notifications card)는 방해 금지 모드가 활성화되면 기록을 숨깁니다. 그 동안 받은 알림은 Dunst에 남아 있으며, 방해 금지 모드가 해제된 후 카드에 다시 나타납니다.

카드는 데스크탑의 실시간 상태를 보여줍니다. 다른 곳(Control Center, 작업 표시줄, 키보드 단축키 또는 `argvus` 명령줄)에서 이루어진 변경 사항은 패널을 다시 시작하지 않아도 패널에 표시됩니다:

| 카드 | 상태가 유래하는 곳 | 새로 고침 시점 |
| --- | --- | --- |
| 사용자 | `getent passwd` | 패널이 열려 있을 때 3초마다 |
| 볼륨 | PipeWire 기본 싱크(`wpctl`) 및 `pactl subscribe` 이벤트 | 각 오디오 이벤트 시 즉시; 안전망으로 2초마다 |
| 외관(텔레메트리, 애니메이션 및 효과) | `/effects` 섹션의 `argvus config` | 패널이 열려 있을 때 2초마다 |
| 전원 | `powerprofilesctl` | 패널이 열려 있을 때 3초마다 |
| 날씨 | 위치 파일 및 wttr.in/Open-Meteo 제공자 | 패널이 열릴 때 및 15분마다; 탭은 현재 상태와 향후 7일간의 일일 예보로 전환 |

외관(Appearance) 카드에는 두 개의 독립적인 스위치가 있습니다. **애니메이션(Animations)**은 `argvus effects-toggle animations toggle`를 실행하며 움직이는 모든 것을 제어합니다. **효과(Effects)**는 `argvus effects-toggle effects toggle`를 실행하며 터미널(Terminal), 실행기(Launcher), 위젯 텔레메트리(Widget Telemetry), 제어판(Control Panel), 작업 표시줄(Taskbar)의 블러 및 투명도를 함께 전환하며, 최소 하나가 켜져 있을 때 켜짐으로 표시됩니다. **SUPER + F6**(`argvus effects-toggle toggle`)는 둘 다 함께 전환합니다. 어느 하나를 변경해도 Hyprland와 테마 소비자들이 즉시 다시 로드됩니다: Waybar는 스타일시트를 다시 읽고, 패널은 IPC를 통해 다시 로드되며, Dunst는 방해 금지(Do Not Disturb)가 활성화되지 않은 경우 구성 파일을 다시 로드합니다. 방해 금지가 활성화되어 있는 경우에는 DND가 꺼질 때까지 다시 로드가 연기됩니다. 어떤 것도 재시작되지 않으며 로딩 화면도 나타나지 않습니다.

작업 표시줄 볼륨 아이콘과 미디어 키에서 스크롤하면 `argvus config audio`가 사용되며, 이 변경 사항은 PipeWire에 적용되고 볼륨이 `/audio`에도 기록됩니다. 따라서 구성 다시 로드는 이전 볼륨을 복원하지 않습니다.

## 세션 동작

`argvus-control-panel.service`는 `argvus-session`에 의해 시작됩니다. 패널을 열고 닫으면 세션 패널 상태가 변경되지만, 이는 모든 카드 동작이 영구 구성이라는 의미는 아닙니다. 네트워크, 오디오, 전원 및 디스플레이 동작은 제공자 또는 현재 데스크탑 세션에 전달될 수 있습니다.

패널, 작업 표시줄 여백 및 창 레이아웃 간의 관계에 대해서는 [taskbar and panels](/docs/argvus-taskbar/taskbar/)를 참조하십시오.

## 나이트 라이트

디스플레이 카드에는 야간 모드 켜기/끄기 스위치와 현재 온도가 표시됩니다. 모서리와 애니메이션은 다른 패널 스위치와 동일한 테마 토큰을 따르며, Sticky 및 Spaced 레이아웃을 포함합니다. 스위치는 테두리가 없으며 다른 패널 스위치처럼 포인팅 핸드 커서를 사용합니다. `argvus config display night-light status|toggle`를 사용하며, 열려 있는 동안 2초마다 폴링하고 액션 후 다시 가져옵니다. 백엔드가 사용 불가능할 때는 행이 숨겨지며, 액션이 실패하면 오류가 표시됩니다. 스케줄링과 온도는 **제어 센터 > 데스크톱 및 입력 > 디스플레이 > 야간 모드**에서 구성됩니다. 예약된 수동 전환은 다음 전환까지 지속되며, 그렇지 않으면 활성화는 지속적입니다.

작업 표시줄 달력, ARGVUS 포커스, ARGVUS 시계 및 제어판은 상호 배타적입니다: 하나를 열면 다른 것이 닫힙니다.

## 컴팩트 다국어 레이블

날씨 탭은 공유 카탈로그(현재 상태 및 7일)를 사용합니다. 날씨 측정값은 동일한 너비의 열을 차지하며, 라벨은 줄바꿈되고 값은 정렬된 상태를 유지합니다. 달력의 요일 약어는 로케일별이며 일요일부터 시작하며, 예측 날짜 라벨도 포함됩니다. 이는 영어 약어를 문자 그대로 번역한 것은 아닙니다.

버튼은 아이콘/라벨 그룹을 사용 가능한 너비에 맞춥니다. 라벨에 생략 기호가 필요한 경우, 버튼 위에 마우스를 올리거나 포커스하면 전체 텍스트를 볼 수 있습니다. 전원 프로필 버튼도 툴팁으로 설명 텍스트를 제공합니다. 긴 스위치 설명은 줄바꿈되며, 숫자 필드와 사용자 입력은 선택한 글꼴에 맞는 충분한 공간을 확보합니다. 카드 높이는 텍스트 줄바꿈에 따라 늘어나며, 하단 카드를 보기 위해 세로 스크롤을 사용합니다. 이러한 변경 사항은 선택된 글꼴과 기존 카드 동작을 유지합니다.
